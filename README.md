# DonorGram — Firebase starter (не полная копия старого приложения)

## Что реально реализовано
- Firebase Authentication: регистрация и вход по email/паролю.
- Профиль пользователя в Firestore.
- Создание групповых/личных комнат с участниками по Firebase UID.
- Синхронизация текстовых сообщений в реальном времени.
- Правила Firestore: чтение комнат и сообщений только участниками; нельзя самостоятельно менять состав комнаты.
- Геолокация только по нажатию пользователя; координаты не отправляются автоматически.
- Адаптивный интерфейс, поиск по уже загруженным чатам, компактный режим.

## Что пока НЕ реализовано
Звонки WebRTC, TURN, доставка/загрузка файлов и фото, передача GPS другому пользователю, каталог и поиск пользователей, блокировки, presence, push-уведомления, реакции/редактирование/удаление сообщений, а также серверный DonAI. Эти функции не маскируются локальными демо-заглушками. Для DonAI нужен отдельный серверный API и секретный ключ модели; для звонков — signaling и TURN; для медиа — Storage с правилами.

## Настройка только проекта `donor-fd6ea`
1. В Firebase Console открой проект `donor-fd6ea`.
2. Включи Authentication → Sign-in method → Email/Password.
3. Создай Firestore Database.
4. В настройках Web App возьми Firebase config и скопируй `.env.example` в `.env`.
5. В `.env` заполни `VITE_FIREBASE_API_KEY`, `VITE_FIREBASE_AUTH_DOMAIN`, `VITE_FIREBASE_PROJECT_ID=donor-fd6ea`, `VITE_FIREBASE_APP_ID` и при наличии `VITE_FIREBASE_MESSAGING_SENDER_ID`.
6. Опубликуй содержимое `firestore.rules` в Firestore Rules.
7. Установи Node.js 20 LTS. Запусти `START_DonorGram.bat` (Windows) или `npm install` и `npm run dev`.

**Важно:** эти правила относятся к Cloud Firestore, не к Realtime Database. Старую RTDB не удаляй и её правила не заменяй ими. Firebase Spark подходит для перечисленных базовых функций. Никаких платёжных данных не требуется.

## Создание чата
Войди вторым аккаунтом, получи его Firebase Authentication UID из раздела Authentication → Users. В первом аккаунте создай комнату и укажи UID второго пользователя в поле участников. Оба участника увидят чат после входа. Не добавляй чужие UID без согласия.

## Проверка
Перед реальным использованием проверь регистрацию двух разных аккаунтов, создание комнаты, чтение/отправку сообщений обоими аккаунтами и отказ третьему аккаунту в доступе. Полный тест Firebase Emulator и e2e в этот архив не включён.
